== Description ==

Xophz Magic Hat is the ultra-minimal semantic parent theme for Project Compass and YouMeOS. Built for modern Full Site Editing (FSE) and traditional WordPress Customizer workflows, Magic Hat features a 24-hour mathematical circadian lighting engine, OKLCH color interpolation, and an AI Page Architect.

== Installation ==

1. Upload the `xophz-magic-hat` directory to `/wp-content/themes/`.
2. In WordPress Admin, navigate to Appearance > Themes and click Activate.
3. Use Appearance > Editor for Full Site Editing, or Appearance > Customize for live design tuning and the AI Page Architect.
